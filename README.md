# 小红获客宝

面向 Codex 的小红书搜索获客技能，覆盖业务诊断、关键词、选题、图文写作、六张贴图、留资钩子、评论私信承接和数据复盘。

## 安装

将本目录复制到 Codex 技能目录，并保持目录名为 `xhs-huokebao`：

```text
~/.codex/skills/xhs-huokebao/
```

重新打开 Codex 后，可直接提出：

> 使用小红获客宝，为我的产品创作一套小红书获客图文交付包。

## 默认交付

- 6 张 1080×1440 PNG
- 3 条标题
- 1 篇正文
- 8–10 个话题
- 5 份评论与私信脚本
- 单文件 HTML 交付页
- 27 个复制或保存入口

## 目录

- `SKILL.md`：技能入口与工作流
- `references/`：方法与规范
- `assets/`：贴图和交付页模板
- `agents/openai.yaml`：Codex 界面元数据
