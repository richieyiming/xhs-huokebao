# ④ 写内容：四框架 + 六句框架 + 标题钩子库

> 公开教学示例：下文人群、故事、时间、数字及报价均是结构演示，不是维护者、客户或真实业务记录；发布时必须替换为使用者已获授权的真实事实，缺证据则删除。

来源：方法论/02（四种内容框架）+ 技能卡 F02（六句框架）+ F01（情景型叙事）+ 方法论/03（标题库/钩子库/图文矩阵）

> **本份管"单条怎么写"**；要"怎么量产"（需求 = 内容主题 = 最小内容组件）→ 见 [14-需求拆解与钩子工程](14-需求拆解与钩子工程.md) 第 3 节。
> 简单说：本份给你一个组件的做法，14 号告诉你一天要产多少个、覆盖多少需求。

## 1. 四种内容框架（按决策阶段选）

| 框架 | 适用阶段 | 模板 | 钩子 |
|---|---|---|---|
| **提问式** | 接触期/了解期 | "[人群]到底能不能做 XX？有没有做成功的姐妹？" | 评论区小号"求带"→ 作者"私信你了" |
| **模糊答案式** | 了解期 | 给方法框架但**不给完整答案**："做 IP 核心就三步：定位→内容→变现。但 90% 的人卡在第一步定位，方向错了后面全白费……" | "想知道自己适合什么定位？私信我" |
| **案例复盘式** | 对比期/决策期 | 给案例、给结果、**没转化点**："素人 IP 孵化 30 天，从 0 粉到变现 5000+，复盘全过程"（配数据截图） | 评论区"怎么报名？"→ 私域承接 |
| **避坑对比式** | 对比期/决策期 | "做 IP 前一定要知道的 N 个坑"/"花 【核心产品价格】 报了个 IP 陪跑，到底值不值？3 个真实学员告诉你真相" | 用"避坑"包装种草，评论区引导私信 |

**模糊答案的人性逻辑**：大众对模糊答案天然有吸引力——被勾到了、戳中需求，但不知道准确答案 → "绿泡泡见"（加微信）。不是骗人，是人性：透露一点有价值的信息，感兴趣了，目的就达到了。

## 2. 六句框架（F02 · 获客文案核武器）

**适用**：要写一条以「让人私信/留资」为目标的文案时（不是品牌曝光，是获客）。
**铁律**：严格按 1→6 顺序，每句一个动作，不许合并、不许跳步。

| # | 动作 | 填空模板 | 目的 |
|---|---|---|---|
| 1 | 圈人扎心 | 在（地域/身份场景），（扎心现状），真的很丢人吗？ | 让对的人停下来 |
| 2 | 树敌共情 | 这（X 年），我见过无数（目标客户）。他们不是不想（理想结果），而是被（行业公敌/乱象）坑怕了。 | 让人觉得你懂他 |
| 3 | 抛资源暗示 | 其实和他们一样，（反向痛点）的（供给方/第二客群）也有很多，我都一一（采访过/聊过/调研过）。 | 埋下"找他就能解决" |
| 4 | 反转定位 | 所以说，（回到第 1 句现状）真的不丢人。因为他们中间，只差一个/一条（你的角色：桥梁/路径/把关人）。 | 自封不可替代角色 |
| 5 | 案例造梦 | 我亲眼见证过，一个（低谷期具体状态，含数字），到（理想生活画面：时间+动作+感官）。 | 用画面代替承诺 |
| 6 | 争议推流 | 你知不知道，为什么那么多人宁愿（忍受现状），也不肯（你期望的行动）？ | 让算法替你打工 |

**口诀**：一问扎心圈住人，二年无数立住身，三句资源轻轻抛，四句反转变桥梁，五句案例造个梦，六句吵架引推流。

**分层理解**：情绪层（1、2、4 句）管人；证据层（3、5 句）管信任；算法层（6 句）管流量。

### 完整样本（知识付费·职场副业）
1. 三十岁了，工资还没过万，真的很丢人吗？
2. 这五年，我带过上千个学员。他们不是不想多一份收入，而是被「三天回本」「躺赚」的割韭菜课割怕了。
3. 其实和学员一样，手里有大把碎片时间、却不知道从哪儿下手的上班族也有很多，他们中的很多人，我都一一聊过。
4. 所以说，工资没过万真的不丢人。因为他们中间，只差一条被普通人反复验证过的、能落地的变现路径。
5. 我亲眼见证过，一个每天挤两小时地铁的行政姑娘，从连朋友圈都不敢发，到靠整理收纳在家接单，第一个月就多赚了四千块。现在她下了班就在自己的小家里接单、改方案，周末还能睡到自然醒。
6. 你知不知道，为什么那么多人宁愿天天刷短视频焦虑，也不肯花一个月，认真学一门能收钱的手艺？

> 关键替换：公敌 = 割韭菜课；角色 = 被验证过的变现路径（规避广告法）；案例锚点 = "行政姑娘""挤两小时地铁"；第 3 句提前接住"没时间"这个最大顾虑。

**更多行业样本**（健身私教 / 家装第三方监理 / 保险经纪 / 留学顾问）见知识库原文：`方法论/07_获客型文案-六句框架资料包.md`。

## 3. 情景型叙事（F01 · 标题与开场的通用改造器）

把「产品展示句」改写成「身份 + 事件 + 人物」的身份共鸣句。

**五步**：
1. 写出原本要说的那句话（产品视角）：「3 分钟教你学会时间管理」
2. 列出目标用户的 **3-5 个具体身份标签**：职场妈妈 / 裸辞青年 / 985 家长 / 二胎妈妈 / 996 程序员
3. 为每个身份匹配一个真实痛点事件：辅导不了三年级数学 / 每天只睡 5 小时 / 生完二胎肚子松垮
4. 套句式：

| 行业 | 句式模板 |
|---|---|
| 知识付费 | 一个【身份】如何用【方法】在【事件】中实现【结果】 |
| 本地生活 | 一个【本地身份】带你去的【场景】，只有【人物】才知道 |
| 教育育儿 | 一个【高身份标签】在【事件】中如何【转折】 |
| 电商好物 | 一个【身份】的【场景】，她/他选了什么【产品】 |
| 健身健康 | 一个【身份】在【事件】后如何用【方法】回到【状态】 |
| 服装穿搭 | 一个【身份】在【场景】中怎么穿出【效果】 |

5. 测试 3-5 条不同「身份 × 事件」组合，找到数据最好的那个后规模化复制

**改造示例**
- ✕「3 分钟教你学会时间管理」→ ✓「一个 35 岁还在职场拼命的妈妈，如何用副业月入过万」
- ✕「5 分钟马甲线训练」→ ✓「一个生完二胎肚子松垮的 35 岁妈妈，如何用碎片时间练回马甲线」
- ✕「成都必吃火锅店 Top10」→ ✓「一个在成都土生土长的出租车司机，带你去只有本地人才知道的深夜食堂」

## 4. 标题库（四类，每类至少备 2-3 条）

| 类型 | 样板 |
|---|---|
| **搜索型** | 普通人做个人 IP，第一步不是拍视频，而是先找到这 3 个答案 / 个人 IP 怎么定位？普通人可以用这 5 个问题找到方向 |
| **痛点型** | 想做个人 IP，却一直不知道自己能做什么？/ 为什么你做了很久小红书，还是不知道自己是谁？ |
| **反常识型** | 个人 IP 最重要的不是人设，而是你能解决什么问题 / 别再问自己"我要做什么 IP"，先问客户为什么需要你 |
| **情绪共鸣型** | 如果你总觉得自己很普通，我反而建议你认真做一次个人 IP / 你不是没有价值，只是过去没有人知道你会什么 |

## 5. 刺激钩子库（每个选题至少备 3 种）

| 钩子类型 | 文案示例 |
|---|---|
| 痛点钩子 | 如果你想做个人 IP，但连续一个月都不知道自己该发什么，这条内容你一定要看。 |
| 反常识钩子 | 我反而建议很多普通人，先别急着拍视频。 |
| 冲突钩子 | 很多人做个人 IP 失败，不是因为能力不够，而是第一步就做错了。 |
| 身份钩子 | 如果你是一个 30 岁左右、想做副业或者个人创业的女性，这个问题你一定遇到过。 |
| 结果钩子 | 给你 5 个问题，回答完，你基本就能找到自己的 IP 方向。 |
| 情绪钩子 | 你有没有发现？很多人能力比你差，却比你更容易获得机会。→ 接："原因可能不是能力，而是他们更会让别人看见自己。" |

## 6. 图文内容矩阵（四类内页结构）

| 类型 | 封面文案 | 内页结构 |
|---|---|---|
| **清单型** | 不知道自己适合做什么 IP？先回答这 5 个问题 | ①我做过什么 ②我最擅长什么 ③我经历过什么 ④我帮别人解决过什么 ⑤什么人愿意为我的能力付费 · 末页：你的 IP 方向，往往就藏在这 5 个问题里 |
| **认知型** | 普通人做 IP，其实有 7 种内容资产 | 经历 · 专业 · 结果 · 观点 · 故事 · 审美 · 人格 · 末页：不要问"我有什么可以拍的"，先问"我过去积累了什么" |
| **诊断型** | 个人 IP 定位最容易犯的 5 个错误 | ①什么都讲 ②只讲自己 ③只讲专业 ④只模仿别人 ⑤只追热点 · 末页：一个 IP 真正需要的是稳定的人群＋稳定的问题＋稳定的价值 |
| **方法型** | 个人 IP 定位公式 | 我是谁 × 我擅长什么 × 我帮助谁 · 末页：再加一个最关键的问题——别人为什么愿意相信你？ |

## 7. 差异化护城河：要有自己的讲法

不只是把"痛点→关键词→标题→内容"做漂亮，而是要形成**个人观点体系**——这才是和普通运营博主拉开距离的地方。

| 维度 | 别人的讲法 | 你的讲法 |
|---|---|---|
| IP 定位本质 | 定位、人设、赛道、内容 | 个人 IP 不是给自己贴一个标签，而是让市场形成一个关于你的稳定认知。 |
| IP 的目标 | 涨粉、曝光、影响力 | 真正的个人 IP，不是让所有人认识你，而是让正确的人在需要的时候想到你。 |
| 普通人做 IP | 先成为网红、先涨粉 | 普通人做 IP，不要先想着成为网红，要先想着成为某一类人的解决方案。 |
