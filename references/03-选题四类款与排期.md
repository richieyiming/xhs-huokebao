# ③ 定选题：四类款选型矩阵 + 排期

> 🔗 **不知道发什么 → 先读 [15-维度乘法与完形填空模板](15-维度乘法与完形填空模板.md)**：把客户需求拆 3-4 个维度相乘，一次出几十到几百条精准选题，再拿回本份排期。问题从「今天写什么」变成「表里还有哪些组合没产」。

来源：技能卡 F03 + 选题模板 1/2/4/5 + 方法论/03（30 条实验计划）

---

## 1. 四类款选型矩阵

按「用户处在哪个决策阶段」反推：写哪一类选题、发哪个号、挂什么钩子。

| 类型 | 用户阶段 | 选题长什么样 | 发哪个号 | 指向产品 | 频率 |
|---|---|---|---|---|---|
| **A 黄金提问流量款** | 接触期/了解期 | 用提问制造争议，泛流量 + 精准粉混捕 | 矩阵节点号（不同人设） | 低门槛钩子产品 | 每号 1 条/天，3 条错开 3 天 |
| **B 身份代入款** | 接触期，有明确身份标签 | 用具体人群切入，打"我也是这种人" | 节点号（按人设严格区分） | 低门槛钩子产品 | 每号 1 条/天，3 条错开发 |
| **D 对比期种草款** | 已在多家对比 | 建立筛选标准，顺带把自己筛进去 | **仅主 IP 号，严禁矩阵号** | 中高客单产品 | 2 条，间隔 7 天 |
| **E 案例见证款** | 观望期，要看效果再决定 | 真实案例建立信任 | **仅主 IP 号** | 破冰 + 中高客单 | 2 条，间隔 7-10 天 |

> ⚠️ 缺口：C 类「痛点拆解款」素材缺失（选题 3），待补。

**开头范式**
- A 类：「总有人问我：2026 年了，普通人做自媒体是不是没机会了？——说句实话：不是没机会，是大部分人的入场姿势就是错的。」
- D 类：「想找 IP 陪跑教练的，先看完这 3 条再交钱。」（先给标准，再暗示自己符合）
- E 类：「她做号两个月，接到了第一个客户。复盘她的节奏，比结果更值得看。」

## 2. 发布窗口

| 类型 | 发布时间 |
|---|---|
| A / B | 工作日 12:00-13:30 / 20:30-22:30 |
| D | 工作日 20:30-22:30（决策时间窗口） |
| E | 工作日 20:30-22:30 + 周末 10:00-12:00 |

---

## 3. 配图与发布规格

- **尺寸**：1080×1440（3:4），发小红书「图文」格式
- **数量**：3 张一组，按「**封面 → 拆解 → 钩子**」顺序上传
- **去查重**：文案复制后**必须用自己口吻改 15%**，避免被平台查重
- **标签**：5-10 个（蹭热度关键词 + 圈人群关键词双轨）

## 4. 节点人设分配（多号时）

每个节点必须有**独立人设 + 独立关键词 + 独立设备**，节点之间内容零重叠、零互动。

| # | 人设 | 主打关键词 |
|---|---|---|
| 1 | 上班族（25 岁，下班做号） | 上班族怎么做 IP / 下班做副业 |
| 2 | 宝妈（带娃在家做自媒体） | 宝妈在家赚钱 / 宝妈做 IP |
| 3 | 大学生（课余做号） | 大学生做自媒体 / 学生党副业 |
| 4 | 实体店老板（转型线上） | 实体店线上获客 / 实体店转型 |
| 5 | 自由设计师 | 设计师个人 IP / 设计师变现 |
| 6 | 职场中层（30+，职业 B 计划） | 30 岁做自媒体 / 职场人副业 |
| 7 | 教师（下班做知识 IP） | 老师做副业 / 知识 IP 怎么做 |
| 8 | 刚创业者（找线上获客方法） | 创业没客户 / 网上怎么找客户 |
| 9 | 副业探索者 | 副业做什么好 / 网上赚钱 |
| 10 | **主 IP 号（你本人）** | 案例复盘 + 深度种草，打对比期/决策期词 |

## 5. 30 条定位实验计划（第一轮验证）

不要一开始就做 100 条。第一轮直接 30 条，验证四组数据：**曝光 → 互动 → 主页访问 → 私信/咨询**。

| 内容类型 | 数量 | 验证目的 |
|---|---|---|
| 搜索型 | 10 | 获取精准搜索流量，验证用户到底搜什么 |
| 痛点型 | 6 | 找到用户情绪共鸣 |
| 认知型 | 4 | 建立个人观点 |
| 方法型 | 5 | 建立专业信任 |
| 案例型 | 3 | 建立真实信任 |
| 转化型 | 2 | 测试咨询需求 |
| **合计** | **30** | 完成第一轮验证 |

**不要把点赞当成第一 KPI——精准咨询比泛点赞重要得多。**

**迭代方式**：同一个痛点，换「标题 → 封面 → 开头 → 视频形式 → 图文形式」做不同版本测试。目标不是找"神奇爆款公式"，而是通过持续发布 + 数据记录 + 迭代，逐渐找到与人群匹配的内容模型。

## 6. 12 周落地时间线

| 周次 | 重点 | 关键动作 |
|---|---|---|
| W1 | 词库 | 种子词下拉推荐、工具拉热度、四阶段各 20-30 词 |
| W2 | 建号 | 5-10 个矩阵号 + 1 主 IP 号，完善简介/背景图/置顶，各发 3-5 条养号内容 |
| W3-4 | 上线 | 完形填空产 48-80 条，矩阵号铺接触/了解期，主号铺对比期；发布后 30 分钟内执行评论区剧本 |
| W5-8 | 放量 | 矩阵号每天 1-2 条，主号隔天；找到爆款框架重复撸干；每天私信导入微信；每周 1 次咨询测 upsell |
| W9-12 | 复盘 | 砍低效账号与框架；爆款用聚光投流放大；主号加学员案例；形成可复制 SOP |

**每周固定动作**：周一拉数据复盘，找爆款、砍低效；每天节点上报私信线索数。
