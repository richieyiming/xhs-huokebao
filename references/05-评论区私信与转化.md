## 1. 为什么评论区比正文重要

**小红书 CES 算法迭代后，评论权重最高。** 小红书本质是"女生宿舍"，要引起讨论——让所有人看到就想评论，流量一定大。

> **发布后不执行评论区剧本 = 内容只发了一半。**

---

## 2. 三步承接法（S01）

### 第 1 步 · 置顶预埋（发布后 30 分钟内）
自己发一条评论并置顶，给犹豫的人一个低门槛入口。
- 模板：「你卡在第__步？评论区聊聊，看到都会回。」
- 变体：「扣【关键词】，完整的__发你。」

### 第 2 步 · 半公开回复（用户留言后立刻）
公开回一句**可感知的干货**，让围观者看到"留资有回报"——**这条回复是说给所有围观者看的，不是只说给提问者**。
- 模板：「__行业第一句可以戳『__』，私我发你完整版。」

### 第 3 步 · 私信转化
**顺序绝不能反：先给（模板/诊断/清单），再收（体验课/咨询/到店）。**

## 3. 评论区剧本（两套）

### 剧本 A：低门槛钩子产品（矩阵号 · 接触期内容）
**图文标题**："上班族到底能不能做小红书 IP？有没有做起来的姐妹？"
**图文内容**：模糊答案——"核心就三步：定位→内容→变现，但 90% 的人卡在第一步……"（大字报形式）

| 角色 | 时间 | 内容 |
|---|---|---|
| 水军 A | 1 分钟后 | "求带！怎么定位啊？" |
| 水军 B | 2 分钟后 | "我也想知道，有没有人教的？" |
| **作者** | 5 分钟后 | "私信你了，可以做个 【入门产品价格】 的 IP 定位诊断，看看你适不适合做 👇" |
| 水军 C | 8 分钟后 | "我做过她的 【入门产品价格】 咨询，真的值！帮我找到了定位方向，少走了半年弯路" |
| 真实用户 | 跟风 | "求带！"/"怎么报名？"/"私信了" |

### 剧本 B：中高客单产品（主 IP 号 · 对比期内容）
**图文标题**："素人 IP 孵化 30 天，从 0 粉到变现 5000+，复盘全过程"

| 角色 | 时间 | 内容 |
|---|---|---|
| 水军 A | 3 分钟后 | "【核心产品价格】 一个月贵吗？效果怎么样？" |
| 水军 B | 5 分钟后 | "我之前就是报的 【核心产品价格】，手把手带比自己摸索强太多了，1 个月就回本了" |
| 水军 C | 8 分钟后 | "【深度交付价格】 三个月的有人做过吗？和 【核心产品价格】 比怎么样？" |
| **作者** | — | "看你的阶段，0 基础建议先做 【入门产品价格】 诊断，有基础的可以直接上陪跑，私信聊" |

### 剧本五法则
1. **先制造氛围**：水军先提"求带""怎么报名"
2. **再给证言**：水军 C 扮演"已购学员"给好评
3. **作者回复留钩子**：永远用"私信你了"而非公开报价
4. **利用从众心理**：真实用户看到满屏"求带"会跟风
5. **利用好为人师**：让真实用户在评论区"分享经验"，增加互动数据

> ⚠️ 执行要求：水军号与主号必须**不同设备、不同网络**；**批量互赞互评是高危行为**，平台能识别同设备同 IP。

## 4. 私信转化四步（低门槛关键词 → 诊断 → 衔接）

不要一上来就卖咨询。设计**低门槛关键词**，引导用户主动私信。

| 步骤 | 动作 | 说明 |
|---|---|---|
| ① 诱饵设置 | 内容中引导："私信我「定位」，领取个人 IP 定位自测框架" | 用户只需发一个词 |
| ② 用户私信 | 用户发送"定位" | 触发回复 |
| ③ 进一步询问 | 职业＋年龄＋目前做什么＋想通过 IP 解决什么问题 | **这一步实际就是客户诊断** |
| ④ 转化衔接 | 按诊断结果推荐对应产品 | 自然过渡，不硬推 |

---

## 5. 线索分级（ABC）

| 等级 | 表现 | 处理 |
|---|---|---|
| **A 类（高意向）** | 主动问"怎么报名""多少钱""怎么开始" | 直接推咨询产品 |
| **B 类（中意向）** | 问方法、问经验 | 发资料 + 案例 → 培育后再推 |
| **C 类（低意向）** | 只互动不私信 | 持续内容触达，不急于推产品 |

**高客单咨询（如 核心/深度交付）必须本人 2 小时内亲自回，禁用自动回复。**

---

## 6. 私域导流的正确姿势

- **九浅一深**：90% 价值内容 + 10% 软植入
- **禁止**：正文/评论直接留微信、二维码（平台零容忍）
- **正确做法**：主页背景图植入活码 / 私信多层级话术 / 评论区"私信你了"
- **谐音规避**：用"薇心""VX"等替代，但只在私信话术里用
- 所有平台导流统一进**企业微信**，自动通过并打标签（来源平台/兴趣点/是否已购）

---

## 7. 完整闭环链路（背下来）

```
用户痛点 → 搜索词 → 标题 → 内容（我是谁+我能做什么+我帮谁）
→ 建立认知 → 刺激互动（你卡在哪一步？）→ 私信扣词 → 咨询 → 成交
```

---

## 8. 坑 / 反例

- ✕ 只在私信里给干货 → 围观者看不到"留资有回报"，后续没人愿意留言
- ✕ 私信里先报价再给东西 → 防御瞬间拉满，线索断掉
- ✕ 用自动回复承接高客单咨询 → 必须本人亲自回
- ✕ 发完就不管了 → 评论区剧本是内容的一部分，不是可选项
- ✕ 节点之间互赞互评 → 被判关联，整组号风险
