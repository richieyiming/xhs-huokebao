# ⑯ 敏感垂类合规边界

本文件用于健康、医美、金融、教育、传统文化与其它高风险类别的内容判断。平台规则与法律会变化，发布前必须查询最新官方规定。

## 1. 三条路线

| 路线 | 内容实质 | 处理 |
|---|---|---|
| A · 可验证信息 | 公开规则、客观参数、生活经验、一般知识 | 可创作，保留来源与边界 |
| B · 主观感受 | 个人体验、文化介绍、生活方式 | 谨慎创作，不外推为普遍结果 |
| C · 结果承诺 | 诊断、预测、保证收益、改变外部结果 | 不创作 |

## 2. 换回测试

不要用谐音、拼音、拆字或暗号给高风险内容换名字。把替代词换回原意，如果内容实质仍是预测、诊断、功效承诺或规避审核，就必须重做。

## 3. 通用红线

- 不预测未来，不推断吉凶，不承诺收益或健康结果；
- 不提供诊断、处方、治疗或投资指令；
- 不以恐惧、疾病、财务焦虑诱导高额消费；
- 不使用前后效果对比、伪造案例或未经授权的用户反馈；
- 不在正文和公开评论中放站外联系方式；
- 不使用高风险象征物、器物或视觉暗示规避文本审核。

## 4. 安全表达方向

- 讲公开信息、选择标准、核验步骤和风险边界；
- 把结果承诺改成可执行的检查清单；
- 把诊断式语言改成一般性观察问题；
- 把“保证有效”改成“适用条件、限制与个体差异”；
- 不确定时显式报备风险并建议人工复核。

## 5. 发布前检查

- [ ] 内容是否属于 A 或 B，且没有滑向 C？
- [ ] 是否有最新官方来源支持规则性判断？
- [ ] 是否删除所有预测、诊断、保证与规避审核表达？
- [ ] 标题、正文、贴图、话题、评论和私信是否全部扫描？
- [ ] 视觉是否也避开高风险暗示？
