# 贴图页面功能与溢出验收

在原有“一题一创作”和品类视觉方案之上，增加页面功能选择与可量化的溢出验收。不是引入固定模板，而是先确定每张图承担什么沟通任务，再为本篇创作对应构图。

## 一、六张图先分工

常用页面功能：

- **封面页**：一句核心主张 + 一个主视觉符号，0.5 秒能懂。
- **解释页**：解释一个问题、原因或认知反转。
- **步骤页**：呈现有顺序的 3—5 步，视觉上必须看得出先后。
- **清单页**：并列呈现检查项、注意点或工具。
- **对比页**：两种做法、前后状态或适合/不适合；不用于违规功效对比。
- **数据页**：一个核心数字 + 口径 + 来源，禁止堆多个无关数字。
- **案例页**：人物/场景/动作/结果，结果必须可核或清楚标明为本人披露。
- **金句页**：一句认知收束，文字少、留白大。
- **行动页**：一个下一步或平台内承接动作。

默认六图可按“封面 → 痛点/解释 → 拆解/对比 → 方法/步骤 → 案例/数据 → 行动”组合，但必须服从本篇内容，不为凑页型硬塞。

## 二、内容容量预算

制作前先给每张图设预算：

- 一页只承担一个核心意思。
- 主标题尽量不超过 3 行，副标题尽量不超过 2 行。
- 清单单页通常不超过 5 项；更多内容拆页。
- 每项尽量控制为“短标签 + 一句解释”，避免一页放小作文。
- 手工换行也计入行数，不能只看字数。

字数只是预警，最终以实际渲染后的行数、边界和手机缩略图为准。

## 三、渲染后强制验收

先渲染封面和信息最满的一页，确认通过后再批量生成。

逐页检查：

1. 画布必须为 1080×1440。
2. 文字与图形不得越过四边安全区；关键内容不进入底部 200px 与右侧 120px。
3. 不得发生裁字、遮挡、重叠、异常换行或文字挤成小字号。
4. 主标题、副标题、正文层级一眼可分。
5. 缩小到手机信息流尺寸后，仍能看懂核心主张。
6. 同组主题、字体、颜色与符号语言保持一致，但构图骨架有变化。
7. 对比页两侧信息量大致平衡；步骤页顺序明确；数据页有口径与来源。
8. 任何页面超载时优先删次要内容或拆页，不优先缩小字号。

## 四、返工顺序

出现溢出或难读时依次处理：

1. 删除重复句和装饰性文字。
2. 把长句改成短标签与具体动词。
3. 将一个页面拆成两个功能页。
4. 调整布局与留白。
5. 最后才小幅调整字号，但不得低于既有最小字号规范。

不要通过压缩行高、挤安全区或隐藏溢出来伪装通过。

## 五、交付记录

在六关自检中增加：

- 六张图是否各有明确页面功能。
- 是否先测试封面与最满页。
- 是否完成行数、边界、缩略图三项检查。
- 是否记录发生过的拆页或删减。
