# ⑭ 需求拆解与钩子工程（工业化流水线）

> 🔗 **上下游**：本份回答「为什么能量产 + 钩子怎么设计」；**「模板从哪来」读 [15-维度乘法与完形填空模板](15-维度乘法与完形填空模板.md)**（拆维度 → 相乘 → 无限选题）。执行顺序：**15 出模板 → 14 定钩子 → 04 写单条 → 11 打包**。

> 上接：[02 挖词](02-关键词挖掘与词库.md) → [04 写内容](04-内容框架与文案模板.md) → [05 收线索](05-评论区私信与转化.md)
> 这一份管「**怎么从手工作坊变成流水线**」——矩阵号能跑到日进万粉，靠的不是内容写得多好，是这套链路跑得通。

---

## 0. 一句话

**把"怎么做内容"变成"填表 → 量产组件 → 放飞钩子"三件事。**
运营的日常工作不是想创意，是**填表**，然后不停生产更多、更全面、更系统、更包裹感的内容组件，每个组件底部挂一个真钩子，持续放飞。

---

## 1. 四步主链路

| # | 步骤 | 产出 | 详细 |
|---|---|---|---|
| ① | **精准需求拆解** | 词库 | 见第 2 节（用 AI 填表） |
| ② | **基于词库搓图文消息** | 内容组件 | 见第 3 节（需求 = 组件） |
| ③ | **设计钩子** | 钩子清单 | 见第 4 节（钩子工程） |
| ④ | **放钩子，持续放飞** | 进粉量 | 见第 5 节（组合与放飞） |

**再简化成一句粗暴版**：**做精准需求分析 → 把关键词全部打包 → 打爆每一个词 → 每个词底下挂钩子。**

---

## 2. 第一步：需求拆解 = 填表（AI 干）

### 怎么干

1. 把你的用户**所有消费行为与习惯**全部列成关键词
2. 工具随便：**Claude / 豆包 / GPT / 任意 AI**
3. 口径：**一个需求 → 裂变 10 个具体关键词**
4. 高客单价行业同理：餐饮、香港保险、留学移民……任何高客单价行业，用户需求全部变成具体关键词

### 填的就是这张表

| 用户阶段 | 他在搜什么 | 他担心什么 | 他想要什么资料 | **他的"鸡蛋"是什么** |
|---|---|---|---|---|
| 接触期 | | | | |
| 了解期 | | | | |
| 对比期 | | | | |
| 决策期 | | | | |

> 最后一列「鸡蛋」是本节新增，见 4.5。前四列与 [02](02-关键词挖掘与词库.md) 的逆向工程共用，不冲突——**02 管"词准不准"，本节管"词够不够多、能不能批量产"**。

### 关键认知

运营这件事，**去年讲的是"怎么做内容"，现在是"填表"**。
表填明白了，内容主题自然就有了——因为**需求就是内容主题**。

---

## 3. 第二步：需求 = 内容主题 = 最小内容组件

这是整段方法论里**最值钱的一条认知**：

```
需求  =  内容主题
内容主题  =  文字
文字 + 图片  =  模板  =  最小内容组件
```

**所以：一个需求 → 一个最小内容组件。**

### 这意味着什么

| 老思路 | 新思路 |
|---|---|
| 今天写点什么？（想创意） | 表里还有哪些需求没产组件？（填表） |
| 一篇是一篇 | 一个需求一个组件，**可批量、可复用、可交给别人做** |
| 靠爆款 | 靠**覆盖率**——更多、更全面、更系统、更包裹感 |

### 运营每天只干一件事

**不停生产更多、更全面、更系统、更包裹感的组件。**

- **更多**：词库里的每个词都要有对应组件
- **更全面**：一个需求从各个角度都被覆盖到
- **更系统**：组件之间能串成体系，不是散的
- **更包裹感**：用户进来以后发现"你把他想问的都答了"

> 配套写法见 [04](04-内容框架与文案模板.md) 的四框架与六句框架——**框架管"单条怎么写"，本节管"怎么量产"**。

## 4. 第三步：钩子工程（最容易做假，也最要命）

### 4.1 钩子只回答一个问题：为什么找你

把这个点**拆到最细节**。不是"我们很专业"，是具体到用户能立刻行动的理由。

| 场景 | 理由怎么给到位 |
|---|---|
| 为什么来你的线下课 | 「我送资料给你，马上过来」 |
| 为什么信你 | 「我自己研发的两万块钱产品，正式售卖的，来了现场就给」 |

### 4.2 为什么高客单价也能在小红书做起来

> 原话：**任何高客单价的项目，在小红书都可以做到。**

逻辑：客单价越高 → 用户决策越重 → **信任成本越高** → 钩子必须越"实"。
所以**不是高客单不能做，是你的钩子配不上这个客单价**。

### 4.3 钩子的四档（按价值从低到高）

| 档 | 形态 | 例子 | 用在哪 |
|---|---|---|---|
| **L1 资料包** | PDF / 清单 / SOP / 表格 | 「香港身份 N 种路径 PDF」 | 通用，接触期 |
| **L2 课程** | 9.9 课 / 直播课 / 录播课 / 文字课 | 同行卖 99 的课程，我们免费送 | 了解期 |
| **L3 自研产品** | 自己研发的产品直接送 | 研发成本两万的产品，现场送 | 决策期 · 高客单 |
| **L4 陪跑 / 全部 SOP** | 过往客户的全套举证 SOP | 「陪跑所有客户的小红书 SOP 资料」 | 高客单终局 |

**选档原则**：钩子价值 ≥ 你准备卖的东西的决策门槛。卖 1682 的，钩子不能只值 9.9。

### 4.4 🔺 铁律：钩子不能是假的

> 原话：「我们的钩子不是假的」「**人不傻**」

- 低质量钩子**骗不进私域**——用户拿到手发现是水货，后续转化直接归零，还反噬口碑
- 自检一句话：**这个钩子，我敢不敢在评论区公开说它值多少钱？**
- 敢说 → 真钩子；不敢说 → 假钩子，重做

### 4.5 "鸡蛋要领"理论（人性底层，填词库必用）

> 一代人有一代人的鸡蛋要领；AI 时代有 AI 时代的鸡蛋；做精准用户，有精准用户的鸡蛋。
> **哪怕是 A9 的大哥，他也有鸡蛋要领。**

案例：做香港保险，A9 客户也要「香港身份 N 种路径 PDF」。

**底层人性就一句：想嫖到有价值的资料。**
免费给他们 → 进私域 → **进入私域之后你还不会吗？你啥都会了。**

**用法**：填 2 节那张表时，最后一列「他的鸡蛋是什么」必填——
不是填"他需要什么"，是填**"他不好意思开口要、但拿到会立刻存下来的那份东西"**。

### 4.6 ⚠️ 表达纠偏（重要）

原始访谈里有大量口嗨表述（"捞鱼""骗子赚钱""把鱼骗到网上"）。
**这些不是方法论，是表演型表达，一律不进本 skill。**

真实逻辑恰恰相反，且原话已自证：

| 口嗨说法 | 真实逻辑 |
|---|---|
| 「骗」 | **钩子必须真的给**（4.4 铁律），人不傻，假钩子转化归零 |
| 「捞鱼」 | 是**精准需求拆解 + 覆盖式投放**，不是广撒网 |
| 「骗子赚钱」 | 是**高价值钩子换信任**再变现，本质是价值前置 |

**照"骗"的思路去做 = 必然翻车。** 本 skill 全部口径以「真钩子 + 真价值」为准。

## 5. 第四步：图文 × 钩子的组合与放飞

### 5.1 组合方式

- **A 中 B 收**：内容讲 A，钩子给 B（用 B 的高价值把 A 的兴趣接住）
- **A 中 A 收**：内容讲 A，钩子是 A 的完整版/深化版

目的只有一个：**让用户看到**。用各种方法让用户看到——中国人人均有自己的"鸡蛋要领"，你的钩子就是那个鸡蛋。

### 5.2 放飞纪律

1. **每一条图文消息底部都带钩子**——一条都不能漏
2. **持续不断地投喂**图文消息
3. 把钩子在小红书的网络中**持续放飞**
4. 矩阵放大：多号 × 多组件 × 多钩子

### 5.3 关于"每天进粉 2 万"

访谈中该操盘手的峰值战绩是**每天最高 2 万进粉**。
**这是他的峰值参考值，不是承诺值，也不是你照做就能到。**

影响变量：账号数量与权重、类目竞争度、钩子档位、组件产能、平台当期政策。
**用法**：当作天花板参考，不当作 KPI。日进粉能稳定到几百 → 已经跑赢绝大多数人。

## 6. IP 化：图文内容体系 → 用嘴巴说出来

> 原话：「我把这个图文的内容体系做好之后，我用我的嘴巴说出来，我就变成了 IP。」

**这是一条内容资产复用链路**，成本极低：

```
词库 → 图文组件 → 口播稿 → 视频号 / 抖音 → IP
```

同一份需求拆解，产出图文和口播两种形态，**不用重新想选题**。

**平台顺序参考**（该操盘手全做过：知乎 → 小红书 → 抖音 → 视频号 → 公众号，最后视频号起量）：
先在一个平台把**内容体系**跑通，再横向复制到其他平台，**不要同时从零开五个平台**。

> 口播稿的具体写法不归本 skill 管（那是 hot-script 的活），本节点只提示：图文体系是口播的现成弹药库。

## 7. 自检清单（做完逐条打勾）

- [ ] ① 用户消费行为与习惯**列成了关键词**，不是只列了行业词？
- [ ] ② 每个需求**裂变出 ≥10 个**具体关键词？
- [ ] ③ 词库里**每个词都有对应的内容组件**？
- [ ] ④ 组件的四个"更"做到了吗（更多 / 更全面 / 更系统 / 更包裹感）？
- [ ] ⑤ 钩子回答了「**为什么找你**」，且拆到了最细节？
- [ ] ⑥ 钩子档位 **≥ 你的客单价决策门槛**？
- [ ] ⑦ 钩子敢不敢**公开说它值多少钱**？（4.4 铁律）
- [ ] ⑧ 「他的鸡蛋是什么」那一列填了吗？
- [ ] ⑨ **每一条**图文底部都挂了钩子？
- [ ] ⑩ 有没有把"骗/捞鱼"当成方法论在用？（有 → 立刻停，回 4.6）

## 8. 坑 / 反例

| 坑 | 后果 | 怎么避 |
|---|---|---|
| **钩子做假**（资料是水货、课是切片） | 进私域也转化不了，还反噬口碑 | 4.4 铁律：敢公开报价才算真钩子 |
| **钩子配不上客单价**（卖 1682 钩子只值 9.9） | 高客单根本推不动 | 4.3 四档选档：钩子价值 ≥ 决策门槛 |
| **只挖词不裂变**（一个需求只写 1 个词） | 覆盖率不够，矩阵跑不起来 | 一个需求裂变 10 个词 |
| **把组件当爆款做**（天天想创意） | 产能上不去，一天产不了几条 | 填表 + 量产，覆盖率 > 单条质量 |
| **漏挂钩子**（有的图文有、有的没有） | 流量白白浪费 | 每一条必挂，无一例外 |
| **拿"日进 2 万"当 KPI** | 预期错位，三天放弃 | 5.3：它是峰值参考值，不是承诺值 |
| **照"骗"的思路干** | 违规 + 封号 + 口碑崩 | 4.6：本 skill 只认真钩子 |

## 9. 通用实战样本（填好的一格）

| 字段 | 值 |
|---|---|
| 行业 | 高客单职业咨询 |
| 用户阶段 | 了解期 |
| 他在搜什么 | 转行怎么选方向 / 职业咨询有没有用 |
| 他担心什么 | 建议太泛、不了解实际经历、花钱后没有行动方案 |
| 他想要什么资料 | 转行决策问题清单、咨询前准备表 |
| **他的"鸡蛋"是什么** | **「12 个转行决策问题 + 咨询准备表」**——能帮助用户先把问题说清楚，也能筛选高意向咨询 |
| 钩子档位 | L1 资料包，后续按需求承接 L3 诊断 |
| 内容组件 | 围绕方向判断、风险边界、准备程度分别制作图文 |
