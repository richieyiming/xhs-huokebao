> **通用化说明**：第 1 节是「素人 IP 孵化」这个行业**填好的完整样例**（照它的结构抄，不是照它的词抄）。
> 换行业时：客户画像换成你的 6 类人群、搜索词换成你的词库、产品换成你的三档（或一档）、案例换成你的真实客户。

## 1. 素人 IP 孵化：完整闭环样本（可直接照抄**结构**）

**业务**：素人 IP 孵化 · 三档产品 999 / 9800 / 29800

### 六类真正客户（表面需求 vs 逆向拆解后的真实需求）

| 人群 | 表面需求 | 真实需求 |
|---|---|---|
| 上班族 | 想做副业 | 不敢辞职但想增加收入，要低风险可验证的路径 |
| 宝妈 | 在家赚钱 | 没有完整时间块，要碎片化可执行、有社群陪伴感 |
| 实体店老板 | 转型线上 | 线下流量萎缩焦虑，想用 IP 引流到店或线上变现 |
| 专业技能者 | 做个人品牌 | 有技能不会变现，不知道怎么定位、包装、找客户 |
| 大学生 | 自媒体赚钱 | 时间多但没方向，要手把手带、低门槛启动 |
| 企业中层 | 打造影响力 | 职场天花板焦虑，想用 IP 做职业 B 计划 |

**逆向工程结论**：用户不搜"素人 IP 孵化"，用户搜的是"普通人怎么做小红书赚钱""0 基础怎么做自媒体""上班族副业做什么好"。

### 完整闭环链路

```
1 用户痛点：我不知道自己适合做什么 IP
      ↓
2 搜索：个人 IP 怎么定位 / 普通人怎么做 IP / 小红书个人 IP 定位
      ↓
3 标题：普通人做个人 IP，第一步不是拍视频，而是找到这 3 个答案
      ↓
4 内容：我是谁 + 我能做什么 + 我帮助谁
      ↓
5 建立认知：个人 IP 不是包装，而是价值表达
      ↓
6 刺激互动：你现在最困惑的是定位、内容、流量还是变现？
      ↓
7 私信：私信"定位"，领取个人 IP 定位自测框架
      ↓
8 咨询：个人 IP 定位咨询
      ↓
9 成交：个人 IP 陪跑
```

### 互动钩子（让评论区变免费需求调研）

> "你现在最困惑的是 A：不知道做什么，B：不知道怎么做，C：做了没人看，还是 D：有人看但没有客户？"
> "如果你愿意，可以把你的职业＋年龄＋目前正在做的事情留在评论区，我可以帮你判断一下你更适合哪类 IP。"

### 案例型内容（差异化关键）

真正拉开与普通运营博主距离的，是**对真实人的诊断能力**——不是"我告诉你一个方法"，而是"我来帮一个真实的人解决问题"。

| 案例选题 | 诊断角度 |
|---|---|
| 一个美容师，怎么从"卖美容服务"变成"个人 IP"？ | 从产品思维到 IP 思维的转化 |
| 一个普通宝妈，如果想做副业 IP，我会怎么帮她定位？ | 零基础人群的定位路径 |
| 一个做了 10 年实体店的老板，为什么我不建议她继续做产品号？ | 产品号 vs 个人 IP 的本质区别 |

### 8 个痛点池复制路线

定位痛点是**第一个样板**。复制到第二个痛点池时，所有字段按同一套结构走。

| # | 痛点池 | 核心问题 | 状态 |
|---|---|---|---|
| 1 | 定位痛点 | 不知道自己适合做什么 IP | 已完成样板 |
| 2 | 启动痛点 | 不敢露脸、害怕熟人、不会表达、镜头紧张、拍不出来 | 待复制 |
| 3-8 | 待规划 | — | — |

**每个痛点池的标准 14 个字段**：核心用户 / 搜索关键词矩阵 / 标题库 / 短视频选题库 / 图文内容矩阵 / 海报主题 / 刺激钩子库 / 互动钩子 / 私信转化钩子 / 对应产品 / 完整闭环链路 / 案例型内容 / 30 条实验计划 / 个人观点。

## 2. 本地生活 · 高客单本地象限样本

**关键词公式**：城市 + 区域 + 具体需求

> 用户搜的是"白云区咖啡店哪家好"，不是你的促销海报。
> ① 不发广告，发答案 ② 关键词越细越准 ③ 爆了的框架反复用

教育行业样本（广州白云区）：
> 广州白云区英语提分的专业机构有哪些？/ 广州白云区高二学生想提分英语该怎么做？
> 地域 + 细分需求词 = 精准线索。搜得这么精准的，就是精准的钱。细分痛点可覆盖：提分、心理问题、兴趣问题。

连锁门店样本：广州从化有什么好吃的？/ 从化特色美食有哪些？/ 广州天气热了有什么好喝？

## 3. 四类款成品笔记样本（改 15% 后可直接发）

### A 类 · 黄金提问流量款（节点号）

**标题**：普通人现在做自媒体，还来得及吗？
**打词**：自媒体怎么做 / 普通人做自媒体｜**扣词**：起号

> 总有人问我：2026 年了，普通人做自媒体是不是没机会了？
> 说句实话：不是没机会，是大部分人的入场姿势就是错的。
> 发 100 条没人看，不是不够努力，是压根没搞清楚——你的用户到底在搜什么。
> 做账号最忌讳"自我表达"，最值钱的是"用户视角"。
> 关键词怎么找？评论区扣【起号】，把素人起号完整路径发你👇

评论区：置顶「说实话，来得及，但只来得及"会做搜索流量"的人。」→ 小号「扣了！求路径图」→ 回复「已私你，记得看消息～」→ 2 小时后追评「姐妹你起步的时候，定位是怎么定的呀？」

### B 类 · 身份代入款（节点号）

**标题**：带娃三年重返职场没人要？我干脆在家做起了账号。｜**扣词**：宝妈

> 宝妈最大的对手不是时间，是"觉得自己没时间"。
> 孩子上学后，我有了每天 4 小时的空档。
> 宝妈做账号，其实是被低估的一批人：
> ① 生活场景真实，天然有信任感 ② 时间少，反而逼你只做高转化的内容 ③ 从"记录生活"切到"解决问题"，涨粉变现都顺了
> 适合宝妈的赛道我整理了一份清单，评论区扣【宝妈】。

> 本地版（实体店）：店里没客人的老板，先别急着投广告。你缺的不是曝光，是"被搜到"。本地获客公式：城市＋区域＋具体需求。用户搜的是"白云区咖啡店哪家好"，不是你的促销海报。扣【门店】发词库模板。

### D 类 · 对比期种草款（**仅主 IP 号**）

**标题**：想找 IP 陪跑教练的，先看完这 3 条再交钱。｜**扣词**：避坑

> ① 看他自己的账号：自己都没结果，拿什么教你
> ② 看交付流程：只有陪聊没有 SOP 的，是花钱买情绪价值
> ③ 看案例：能验证的才叫案例，截图都不给的直接 pass
> 还有 2 条更狠的标准，一条就能筛掉 80% 的浑水摸鱼。
> 评论区扣【避坑】，完整的筛选清单发你。

评论区：置顶「先筛人，再交钱，顺序别反。」→ 回复「私信说清楚你目前阶段+预算+期待，我帮你看适不适合。」
**发布建议**：每一条评论都要亲自认真回；可追评「说实话现在市面上 90% 的陪跑都达不到这 3 条」强化信任。

**D2（讲产品差异，可投薯条 50-100 元/条测私信转化）**：999 的咨询和 9800 的陪跑，差在哪？→ ①999 咨询＝定位诊断 ②9800 陪跑＝落地执行 ③咨询解决"往哪走"，陪跑解决"走过去"。方向都没想清楚就冲陪跑，大概率白花钱。扣【诊断】。

### E 类 · 案例见证款（**仅主 IP 号**）

**标题**：她做号两个月，接到了第一个客户。｜**扣词**：复盘

> 复盘她的节奏，比结果更值得看：
> ① 第 1-2 周：一条内容不发，只做用户逆向分析——之前她跳过这步，白干一个月
> ② 第 3-6 周：只打一类关键词，一周 5 条图文持续铺
> ③ 第 7 周：首条笔记冲进搜索前 5，私信开始进人
> 没有奇迹，只有顺序对了。
> 她挖关键词的方法我做了复盘，评论区扣【复盘】。

评论区：置顶「没有奇迹，只有顺序。」→ 小号「第 7 周才进粉，会不会太慢了？」→ 回复「她前一个月是乱的，顺序对了会更快。」
**发布建议**：案例号不要一上来就讲产品，先讲"人 + 过程"，越真实越好；**学员本人愿意出镜，转化率能翻 3 倍**。

## 4. 健康与功效类：通用合规要点

健康相关内容应使用确定、可验证的信息替代功效承诺。

| 类别 | 禁用 | 可讲 |
|---|---|---|
| 功效表达 | 治疗 / 预防 / 治愈 / 根治 / 降三高 / 清肺 / 护血管 / 增强免疫力 / 抗氧化 | 日常营养补充 / 成分含量 / 食用方法 |
| 绝对化用语 | 《广告法》§9 绝对化用语 | 用户自述体验（"个体差异请参考"） |
| 承诺 | 无效退款 / 100% 天然 | 检测报告 / 溯源故事 |
| 导流 | 挂购物链接、留联系方式 | 企业微信承接、客服组件 |

- 法律和平台规则会变化，发布前应查询最新官方规定。
- 钩子不用功效承诺，可提供成分查询方法、标签阅读清单、来源核验路径等确定性信息。
- 主观承诺性表达在小红书受限，只讲成分/含量/食用方法，全程 0 功效词
- 备好合规话术卡；发布前过一遍红线自查
