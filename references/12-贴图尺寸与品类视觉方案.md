## 一、尺寸：为什么是 1080×1440（3:4）

小红书发现页是**双列瀑布流**，竖版图在信息流里占的屏幕面积最大（约为横版的 1.5 倍），点击率天然占优；横图（4:3）会被系统强制裁成 3:4，上下内容直接丢失。

| 比例 | 像素 | 什么时候用 |
|---|---|---|
| **3:4（默认，99% 场景）** | **1080×1440** | 攻略、清单、种草、知识卡、案例、钩子——**整组图统一用它** |
| 1:1 | 1080×1080 | 只发单图的产品特写、九宫格凑版 |
| 4:3 | 1440×1080 | 表格、教程截图、横版对比 |

**硬性**：
- 一组图**必须同比例**——系统以第一张为基准裁切其余图，混着传等于白做
- 高清备选 1242×1656（严格 3:4）或 1242×1660；日常 1080×1440 足够，文件不大、加载快
- 格式 jpg/png，**单张 ≤5MB**
- 6 张按 1→6 顺序上传

## 二、安全区：别让关键信息被系统 UI 吃掉

信息流里画面会被叠东西，**核心文字与主体放在画面中上部 2/3**：

| 位置 | 被什么遮 | 处理 |
|---|---|---|
| 底部约 200px | 笔记标题 + 作者头像 | **不放文字**，留白或放低对比度装饰 |
| 右下角约 120px | 点赞/收藏按钮 | 不放数字、不放关键词 |
| 四周 | 圆角裁切 | **四边留 ≥88px**（约 8%），模板已按 96px padding 处理 |

**字阶（缩略图也要能读）**：

| 层级 | 字号 | 说明 |
|---|---|---|
| 主标题 | 88-104px | 封面≤20 字，最佳 8-15 字；2-3 行，每行≤7 字 |
| 副标题/引子 | 44-48px | 主标题的 50-60% |
| 条目正文 | 48-56px | 一行一条，不写长句 |
| 最小字号 | **≥32px** | 低于这个缩略图全糊 |
| 落款/页码 | 32px | 放底部安全区之外的最下方，弱化处理 |

**字体**：主标题 + 副标题**最多 2 种**；主标题必须加粗；**禁用花体/艺术字**（部分机型乱码 + 限流）。

## 三、13 套常规品类视觉方案

> 用法：在 `shot-template.html` 的 `<body>` 上挂对应 class，全组 6 张一次性换肤。
> 每套给的是「氛围配方」，不是死规矩——按具体产品的调性微调，但**主色不要超过 2 个 + 强调色 1 个**。

### 1. 知识 / IP / 商业 / 职场　`class="t-knowledge"`
- **背景**：米白 `#FAF8F4`　**卡片**：白　**墨色**：`#1D1D1F`
- **强调色**：金 `#C9A84C`（金底 `#FBF6E9`）
- **氛围词**：克制、专业、值钱
- **装饰**：顶部 10px 细金线、细直线分割、几何色块（圆/方/斜切），**大留白**
- **产品呈现**：不出现实物，用**图文卡片 + 数据块**代替；出现人也只用侧影/半身
- **例**：个人 IP 孵化、创业咨询、职场课、运营方法论

#### 1.1 🔺 知识 / 自我认知类：必须配「主视觉符号」（2026-09-16 新增）

> **完整的创作方法见 [18-贴图主视觉创作标准](18-贴图主视觉创作标准.md)**（四类词翻译表 + 六张符号配额 + 执行纪律 + 三问自检）。
> 本节只给最小可执行版。

**问题**：纯文字排版（标题 + 条目 + 金句）信息准确，但整组六张都是文字块，在信息流里**没有吸引力、抓不住眼**——用户反馈"纯文本看起来很没有吸引力"。

**规则**：知识 / IP / 自我认知 / 职场类走 `t-knowledge` 时，**除文字之外必须有一个主视觉符号**，且整组六张**共用同一套符号语言**（封面用主符号做徽标，内页每张配一个衍生符号 + 页眉符号行）。

**装饰四件套**（低成本大幅提质感，可无脑叠加）：

| 元素 | 做法 |
|---|---|
| 点阵底纹 | `radial-gradient(var(--dot) 1.7px, transparent 1.8px)` + `background-size:38px 38px`，透明度 0.085（深色底用金色点 0.16） |
| 金色柔和光晕 | 两个 `radial-gradient`（右上 + 左下），透明度 0.13-0.30 |
| 超大低透明水印序号 | 400px 数字、`opacity:.042`、放在标题右侧，只做质感不抢信息（与数据图重叠时降到 .028） |
| 页眉符号行 | 左侧「小符号 + 分类标签（如"痛点 · 共情卡"）」+ 底部 2px 细线，右侧序号 |

**封面走深色**：墨黑 `#141416` + 金，在浅色信息流里对比更强、缩略图更抓眼；内页保持米白，形成「1 深 5 浅」的节奏。

**可直接复用的 6 个符号语义**（纯 SVG 几何图形，实现见 `assets/shot-build-v2.py`）：

| 符号 | 画法 | 语义 |
|---|---|---|
| **光核** | 同心三环 + 金色轨道弧 + 中心光点 | 自带光源 / 主视觉徽标 |
| **准星** | 圆 + 十字定位线 + 中心点 | 找不到自己的位置 |
| **断环** | 圆环 + 斜切线 | 走错的路 / 误区 |
| **阶梯路径** | 三段上升折线 + 节点圆点 | 正确的顺序（配竖向时间线列表） |
| **收敛线** | 四线由宽收拢到一点 + 光环 | 把力气收到一个点上 |
| **信笺折角** | 圆角矩形 + 折角 + 内容线 | 资料发你 |

**🔺 敏感垂类红线**：符号只能是**通用几何**（圆、弧、直角、折线、矩形、点阵）。
**禁止**使用可能暗示预测、诊断或规避审核的器物与符号——一律按 [16-敏感垂类合规边界](16-敏感垂类合规边界.md) 处理。

**验收加一问**：把六张缩到信息流缩略图大小，封面能"一眼看出是什么调性"吗？

### 2. 美妆 / 护肤　`class="t-beauty"`
- **背景**：奶油白 `#FFF9F7`　**墨色**：`#3A2E2B`　**强调**：裸粉 `#E0A899`
- **氛围词**：柔软、干净、有光
- **装饰**：大圆角卡片（24px）、柔和阴影、细弧线
- **产品呈现**：瓶罐平铺实拍 / 质地特写（奶油感、水感），**人物只用局部（手、眼下、唇）**
- **禁区**：前后对比图、肤色承诺、"医美级"等词

### 3. 穿搭 / 时尚　`class="t-fashion"`
- **背景**：米杏 `#F6F2EC`　**墨色**：`#22201E`　**强调**：焦糖 `#B98A5E`
- **氛围词**：高级、松弛、质感
- **装饰**：极细衬线标题、超大字距、大量留白、1px 分割线
- **产品呈现**：全身/半身实拍为主，人物头顶留 150px、脚底留 100px，主体占画面中心 60% 以上
- **例**：女装店、买手、形象管理

### 4. 家居 / 家装　`class="t-home"`
- **背景**：暖白 `#FBF7F0`　**墨色**：`#33302B`　**强调**：原木 `#C4A484`
- **氛围词**：生活气、温度、烟火
- **装饰**：木纹/棉麻质感色块、柔和自然光感、圆形裁切
- **产品呈现**：**场景实拍第一**（摆进真实家里），不用白底产品图
- **例**：全屋定制、软装、收纳、家清

### 5. 美食 / 餐饮 / 烘焙　`class="t-food"`
- **背景**：奶油黄 `#FFFBF0`　**墨色**：`#3B2F22`　**强调**：暖橙 `#E08A3C`
- **氛围词**：香、热乎、手作
- **装饰**：手绘感线条、圆点、波浪分隔、浅木色块
- **产品呈现**：**成品特写占主视觉 50% 以上**，热气/酱汁/断面细节；步骤用小方格
- **例**：烘焙工作室、探店、预制菜、私房菜

### 6. 母婴 / 亲子　`class="t-mom"`
- **背景**：柔粉 `#FFF6F7`　**墨色**：`#3D3033`　**强调**：奶粉 `#F2A9B4` / 天蓝 `#9CC5E8`
- **氛围词**：软、安心、亲昵
- **装饰**：圆润无锐角、手绘小图标、云朵/小动物轮廓
- **产品呈现**：真实育儿场景 > 产品特写；出现孩子**必须打码或只拍背影/局部**
- **例**：月子中心、早教、辅食、童装

### 7. 健身 / 运动 / 体态　`class="t-fitness"`
- **背景**：深灰 `#1F2124`（可深色）　**墨色**：白 `#FFFFFF`　**强调**：荧光绿 `#C8F04A`
- **氛围词**：力量、克制、燃
- **装饰**：斜切色块、粗数字、进度条、网格
- **产品呈现**：动作剪影/器械局部；**不出现身材对比图**
- **例**：私教、普拉提、体态管理、运动装备

### 8. 旅行 / 本地生活 / 探店　`class="t-life"`
- **背景**：天空白 `#F7FBFF`　**墨色**：`#1F2A33`　**强调**：青蓝 `#5AA9C9`
- **氛围词**：开阔、清爽、想去
- **装饰**：照片压暗+大字、地图路线线稿、圆角相框
- **产品呈现**：**实景大图做底**，文字压在留白区（注意安全区）
- **例**：民宿、旅行社、同城门店、亲子营地

### 9. 教育 / 学习 / 考试　`class="t-edu"`
- **背景**：冷白 `#F8FAFD`　**墨色**：`#1E2A38`　**强调**：蓝 `#4A7FB5`
- **氛围词**：清晰、可信、有效
- **装饰**：方格本纹理、清单勾选框、编号块、进度条
- **产品呈现**：笔记/讲义/错题本实拍，或纯文字卡
- **禁区**：**不承诺分数、不承诺上岸、不出现"保过"**

### 10. 金融 / 房产 / 保险　`class="t-finance"`
- **背景**：深蓝 `#0F2740`（可深色）　**墨色**：白　**强调**：金 `#D4AF6A`
- **氛围词**：稳、专业、长期
- **装饰**：细金线、数据图表线稿、城市剪影
- **产品呈现**：**不出现收益数字承诺、不出现"稳赚"**；用图表趋势线示意（不标收益）
- **例**：保险经纪、房产咨询、家庭财务规划

### 11. 情感 / 心理 / 关系　`class="t-emotion"`
- **背景**：雾紫 `#F7F4FA`　**墨色**：`#38313F`　**强调**：藕荷 `#A98CC4`
- **氛围词**：被理解、松弛、温柔
- **装饰**：柔和渐变、模糊光斑、手写感短句
- **产品呈现**：**不出现真人正脸**；用手、背影、空镜（窗、咖啡、书）
- **例**：婚恋咨询、心理咨询、女性成长

### 12. 非遗 / 文创 / 手作　`class="t-craft"`
- **背景**：宣纸米 `#F7F1E5`　**墨色**：`#2B2118`　**强调**：朱砂 `#B03A2E`
- **氛围词**：东方、手温、讲究
- **装饰**：宣纸纹理、印章方框、竖排短句、留白极多
- **产品呈现**：器物特写（茶器、木作、织品）、手部动作特写
- **例**：陶艺、茶道、汉服、文玩（文玩注意别碰"升值"话术）

### 13. 生鲜 / 农产品 / 特产　`class="t-fresh"`
- **背景**：米白 `#FCFAF3`　**墨色**：`#2F3A2B`　**强调**：草绿 `#6E9E5A` / 土黄 `#D9A441`
- **氛围词**：产地、新鲜、实在
- **装饰**：田垄线条、产地标签、手写价格牌
- **产品呈现**：**产地实拍 > 精修图**；带泥、带叶、带手更有说服力
- **例**：水果、土特产、农庄、预制农产品

## 四、5 套敏感品类的「隐晦视觉方案」

> **总原则**：敏感品类**整篇降级为「文化 / 生活方式 / 感受」**，贴图走氛围，不碰功效、诊断、结果承诺、身体特写、前后对比。
> 暗语怎么写见 [09-违禁词与暗语替换表](09-违禁词与暗语替换表.md)。

### A. 国学 / 命理 / 八字 / 风水　`class="t-guoxue"`
- **视觉**：宣纸米 `#F7F1E5` + 墨黑 `#2B2118` + 朱砂 `#B03A2E`
- **走什么调**：**东方美学 / 传统文化知识**——像在讲"古人的生活方式"，不像在算命
- **可用的意境元素**：山水留白、印章方框、竖排短句、节气、器物（茶、香、书）、书法字（用系统字，别用生僻篆体）
- **贴图怎么表达**：讲"性格说明书""空间感""选日子的门道""调状态"，**用图形示意（线条、方位框）**
- **绝对禁止出现**：罗盘/铜钱/符咒/卦象实拍、手掌纹路特写、生辰八字表格、"改运/化煞/破灾"字样

### B. 男性私密 / 男科健康　`class="t-male"`
- **视觉**：藏青 `#1C2733`（深色）+ 浅灰白字 + 冷银 `#9AA7B4`
- **走什么调**：**成熟男士的生活方式 / 状态管理**——像男士理容、健身、职场状态，不像看病
- **可用的意境元素**：晨跑、咖啡、腕表、书桌、健身房剪影、深色调质感
- **贴图怎么表达**：讲"状态、精力、底气、节奏"，**只用氛围图和文字卡**
- **绝对禁止出现**：身体部位、药品/胶囊、检查单、"肾/痿/泄/前列腺炎"任何字、前后对比

### C. 女性私密 / 妇科 / 内分泌　`class="t-female"`
- **视觉**：莫兰迪粉 `#F6EEF0` + 雾紫灰 `#6E5F68` + 藕 `#C9A9B4`
- **走什么调**：**悦己 / 身体感受 / 松弛感**——像女性成长、身体护理日记，不像诊疗
- **可用的意境元素**：花、浴室水汽、香薰、柔软织物、手写日记、晨光
- **贴图怎么表达**：讲"小花园、身体信号、周期性、节奏"，用**柔和插画或空镜**，不画身体结构
- **绝对禁止出现**：医学示意图、私处相关任何图、药品、症状清单、"治疗/治愈"字样

### D. 医美 / 轻医美 / 整形　`class="t-medical"`
- **视觉**：冷白 `#FDFDFE` + 浅灰 `#8A8F98` + 浅金 `#C7B49A`
- **走什么调**：**高级感 / 轮廓美学 / 皮肤管理**——像生活方式杂志，不像手术宣传
- **可用的意境元素**：极简线条画（脸部轮廓线稿）、皮肤质感微距（不露全脸）、留白、细字
- **贴图怎么表达**：讲"轮廓感、皮肤管理、保养项目"，**用线稿或局部微距**
- **绝对禁止出现**：术前术后对比、真人正脸特写、项目名称（玻尿酸/热玛吉/水光针）、机构招牌、价格

### E. 保健 / 养生 / 功效食品　`class="t-health"`
- **视觉**：米白 `#FAF9F2` + 墨绿 `#3E5646` + 草绿 `#7FA26B`
- **走什么调**：**日常养生 / 生活方式**——像在分享"我的一天"，不像卖保健品
- **可用的意境元素**：食材、茶、早晨餐桌、散步、泡脚、节气
- **贴图怎么表达**：讲"日常节奏、身体感受、怎么吃怎么睡"，**用生活场景实拍**
- **绝对禁止出现**：功效承诺、前后体检单对比、胶囊/瓶罐特写、"治疗/预防/根治"

## 五、执行顺序（别跳步）

1. 定品类 → 在 [12] 里选一套视觉方案（常规 13 选 1 / 敏感 5 选 1）
2. 打开 `assets/shot-template.html`，给 `<body>` 挂上对应 class
3. 只改 6 个 `.shot` 里的文字（不动 CSS）
4. **先截第 1 张验证版式与配色**，确认没问题再批量截另外 5 张（算力纪律：先小样再批量）
5. 命名 `01-封面.png`…`06-钩子.png` → 放进交付包 `images/`

**验收三问**：缩略图里主标题能读清吗？安全区没压到东西吗？敏感品类有没有露出任何禁用元素？
