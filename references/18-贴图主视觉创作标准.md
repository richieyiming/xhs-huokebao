# ⑱ 贴图主视觉创作标准（一题一创作）

> 🔺 这一份管「贴图怎么长出来」。**贴图不是套模板，是从文案里长出来的。**
> 上接：[12 贴图尺寸与品类视觉方案](12-贴图尺寸与品类视觉方案.md)（管尺寸/配色/品类禁区）
> 配套实现：`assets/shot-build-v2.py`（符号绘制 + 版式 + 出图脚本，改文案即可复用视觉语言）

---

## 0. 一句话标准

**先读文案，再定画面。** 每一组贴图都要为「这一篇在说什么」单独设计一套视觉隐喻。

能复用的只有**视觉语言**（符号语法、配色、底纹、字阶）；**不能复用的是整套版式与图形本身**。

| | 长什么样 |
|---|---|
| ❌ 不合格 | 文案换了，贴图还是上次那六张的壳，只改了字 |
| ✅ 合格 | 文案讲"把力气收拢"，画面就出现收拢的线；文案讲"顺序错了"，画面就出现阶梯与断口 |

## 1. 五步：从文案生成画面

| 步 | 干什么 | 输出 |
|---|---|---|
| **① 读文案** | 标题 + 正文通读一遍，用一句话说清这篇在讲什么 | 一句话主旨 |
| **② 抓四类词** | 从文案里圈出「状态词 / 过程词 / 位置词 / 数量词」，它们就是画面素材 | 词表 |
| **③ 翻译成几何** | 每类词对应一种几何关系（见 1.1 对照表） | 3-6 个符号草图 |
| **④ 定一套语法** | 选一条视觉语法贯穿六张（如"细线 + 圆 + 直角 + 点阵 + 金"） | 视觉规则 |
| **⑤ 定节奏** | 封面深色立主张，内页浅色讲道理（1 深 5 浅） | 明暗排布 |

### 1.1 🔺 四类词 → 几何关系对照（翻译表）

| 文案里出现 | 长什么样 | 例 |
|---|---|---|
| **状态 / 情绪** | 形状的"身体语言"：断口 = 走错、收拢 = 聚焦、松散 = 内耗、向上 = 成长、重叠 = 交集 | "什么都学一点" → 断环 |
| **过程 / 顺序** | 路径：阶梯、时间线、连线、分岔、回环 | "正确的顺序" → 三段阶梯 + 竖向时间线 |
| **位置 / 定位** | 坐标：十字准星、圈、点、坐标轴、靶心 | "找不到自己的位置" → 准星 |
| **数量 / 反差** | 大小与多少：大数字、收敛锥、倍数块、进度条 | "90% 的精力" → 金字大数 + 四线收拢一点 |
| **交付 / 给出** | 物件：信笺、卡片、折角、礼盒、开封 | "PDF 发你" → 信笺折角 + 虚线资料条 |

> **翻译的原则：只画关系，不画东西。** 文案讲"纠结"→ 画两条打结的线，不画表情包；
> 讲"理不清"→ 画缠绕的螺旋，不画一团乱的线团。"关系"能抽象成几何，"东西"就变成了插画（贵、还容易违规）。

## 2. 六张的分工与符号配额

| 张 | 角色 | 符号类型 |
|---|---|---|
| **01 封面** | 立主张 | **主符号**（全组的"logo"）+ 深色底 + 一句最狠的话 |
| **02 痛点** | 让人对号入座 | 状态类（准星 = 找不到位置） |
| **03 拆解** | 拆掉错误做法 | 断裂类（断环 / 断线 / 斜切） |
| **04 方法** | 给顺序 | 路径类（阶梯 / 时间线 / 节点） |
| **05 案例** | 给证据 | 数量类（大数字 / 收敛 / 进度） |
| **06 钩子** | 让人动手 | 物件类（信笺 / 卡片）+ 实心 CTA 块 |

**一组的符号必须同族**：同一种线宽、同一种金、同一种圆角、同一套留白节奏。
六张摆在一起要像"同一个人的作品"，不是六张拼图。

---

## 3. 覆盖面积与配额的硬规矩

- 一张图里**图形面积 ≤ 1/4 画面**，文字永远是主角 → 图形只做三档：**页眉徽标 + 角落水印 + 局部配图**
- **一张图只讲一个视觉概念**（一个符号 + 一句结论），不堆符号
- 装饰件（点阵 / 光晕 / 水印序号 / 细线）只管氛围、不承担含义 → **可以跨组复用**；含义件（6 个符号）必须本组原创
- 封面例外：主符号可放大到 200-260px，因为封面要靠它立调性

---

## 4. 执行纪律

1. **先写"视觉脚本"再动手**。用一句话排出六张的画面，例：
   > 「光核立主张 → 准星找不到位置 → 断环拆三种错 → 阶梯给顺序 → 收敛给证据 → 信笺给资料」
   写完再作图；写不出来 = 还没读懂文案，回去读
2. **先出封面小样**：封面定调性，封面过了再批量出另外 5 张（沿用 [12] 的算力纪律：先小样再批量）
3. **内容边界要实测**：单张可用高度 = 1440 − 上留白 − 200（底部安全区）；出图后用浏览器量金句块底部，**必须 ≤ 1240px**，超了就是溢出
4. **字号下限 32px**：装饰字、分类标签、页码都不许低于 32px（低于这个缩略图全糊）
5. **交付前缩略图测试**：把六张缩到信息流尺寸，封面要"一眼看出调性"，内页要"一眼看出是干货"

---

## 5. 🔺 禁用与红线（与 [16-敏感垂类合规边界](16-敏感垂类合规边界.md) 联动）

- **符号只能是通用几何**：圆、弧、直角、折线、矩形、点阵、箭头
- 敏感垂类禁止使用可能暗示预测、诊断、收益保证或规避审核的器物与符号。
- 其它品类禁区按 [12](12-贴图尺寸与品类视觉方案.md) 对应方案走（身体部位、前后对比、药品、真人正脸等）
- **不许为了好看加与文案无关的图形**：装饰件只做氛围，含义件必须能被一句话解释

## 6. 三问自检（做完必答）

| 问 | 不合格的样子 |
|---|---|
| **一图一义**：这张图的图形，能用一句话说出它和文案的关系吗？ | 说不出 = 纯装饰，删掉 |
| **缩略图**：缩到信息流大小，主标题还读得清、调性还认得出吗？ | 读不清 = 字太小或被图形抢戏 |
| **换文案测试**：把这套图配到另一篇完全不同主题的文案上，还成立吗？ | 还成立 = 你没为这篇做设计，返工 |

---

## 7. 反例（踩过就返工）

| 反例 | 为什么不行 |
|---|---|
| 六张全是文字块，只靠字号和分割线区分 | 信息流里抓不住眼——用户原话"纯文本看起来很没有吸引力" |
| 只给封面加了图标，内页五张照旧 | 一组不统一，像临时拼凑 |
| 每张换一个不相干的漂亮图形 | 不是一套视觉语言，账号没有识别度 |
| 图形占比过大，压住文字 | 信息传不出去，点进来也留不住 |
| 复用上一组整版版式只改字 | 违反"一题一创作"，账号看起来像模板号 |
