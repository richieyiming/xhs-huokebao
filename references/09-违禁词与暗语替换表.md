## 一、通用违禁词（任何行业都躲）

| 类别 | 禁用/高危 | 换成 |
|---|---|---|
| 绝对化用语（广告法§9） | 最好、第一、顶级、极致、唯一、首选、国家级、世界级、完美、100%、绝对、永久、独家、全网最低 | 我自己常用的、比较顺手的、排得比较靠前、多数人反馈还行 |
| 医疗功效（广告法§17，最高罚 32 万） | 治疗、治愈、根治、预防、药效、抗炎、杀菌、疗效、处方 | 日常养护、体感、日常补充、生活方式 |

| 导流（平台零容忍） | 微信、加微、V 我、二维码、手机号、QQ、公众号、外链、某宝、下单、点击链接 | 评论区扣【XX】、主页看、后台滴滴、绿泡泡（仍建议只在私信里出现） |

## 二、敏感品类暗语对照（重点）

**总原则：敏感品类整篇降级为「感受 / 生活方式 / 文化知识」表达，不触及功效、诊断与结果承诺。**
暗语要让**目标人群一眼看懂、平台机器读不出品类风险**。

### 1. 国学 / 命理 / 八字 / 风水

| 禁用词 | 暗语 |
|---|---|
| 算命、算八字、看相、占卜、预测、吉凶、命理、紫微斗数 | 性格说明书、天赋地图、了解自己的说明书、出生时间里的信息 |
| 转运、改运、化解、化煞、开光、符咒、法事、通灵、驱邪 | 调状态、换节奏、给自己一个仪式感、清理一下、顺一顺 |
| 风水、财位、煞气、阴阳 | 空间感、居家布置、动线、采光、住得舒服、能量场 |
| 择日、黄历、宜忌 | 选日子的门道、挑个顺的日子、老辈人讲究 |
| 大师、师傅（宗教指向） | 老师、研究这个很多年的人、家里长辈传下来的说法 |

> 表达方向：讲「文化、审美、自我认知、生活方式」，不讲「预测与改变命运」。

> ### 🔺 换回测试（用暗语前必过，新增）
> **把暗语换回原词，这个内容还成立吗？**
> - 换成"算命"后**读不通**（因为内容真的只是在讲性格 / 文化 / 自我认知）→ ✅ 合规内容，用暗语是对的
> - 换成"算命"后**完全读得通、而且更准确** → ❌ 说明实质就是算命，**换名字没用，回去重做内核**
>
> **暗语的用途只有一个**：让**本来就合规**的内容避开机器误判。
> **暗语不是给违规内容换马甲的工具**——2026 年是机器 + 人工双重校验，人工看的是内容实质（日主、身强身弱、大运流年），不是名字。
> 完整判定见 [16-敏感垂类合规边界](16-敏感垂类合规边界.md)。

## 三、替换流程（四步，交付前必走）

1. **扫**：把标题 + 正文 + 6 张贴图文案 + 5 份评论区脚本合并成一份文本，逐条比对上表
2. **换**：命中即替换；敏感品类整段降级为"感受/生活方式"表达
3. **降级**：仍擦边的表述 → 直接删掉（宁可少一句，不可多一句风险）
4. **报备**：有无法 100% 规避的风险点 → 在交付时**显式列出**（哪个词、为什么难替、建议怎么发）

## 四、行业术语的人话翻译（通用要求）

小红书人群不吃专业术语。任何行业的行话都要翻译成"用户生活里的话"：

| 行业 | 行话 | 人话 |
|---|---|---|
| 保险 | 保额 / 现金价值 | 万一出事能拿多少 / 中途退能拿回多少 |
| 医美 | 面部折叠度 | 侧面看是不是更立体 |
| 命理 | 印星 / 食伤 | 你到底是靠脑子的还是靠手艺的 |
| 家装 | 增项 / 闭口合同 | 中途会不会加钱 |
| 教育 | 认知负荷 | 一次塞太多记不住 |

**自检**：文案里任何一个词，你妈能不能一眼看懂？看不懂就换掉。
