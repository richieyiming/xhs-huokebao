# ⑩ 交付前强制自检清单（每次出图文包必过 · 有一项否就不许交付）

> **性质**：闸门，不是提示。交付前逐项回答"是/否"，任何一项为"否"→ 停下修正，**不许带病交付、不许"先给用户看看再说"**。
> **用法**：交付后在回复里逐项列出打勾结果，让用户一眼能核验。

---

## 第一关 · 通用化与选题关

- [ ] **① 行业已替换**：本行业的具体产品/人群/词库都填进去了吗？**不是直接照抄素人 IP 样例**？
- [ ] **② 象限结论**：已判定「客单价 × 覆盖范围」，打法（铺量 / 种草 / 地域精准 / 中心化）与之一致？
- [ ] **②⁺ 业务场景已判定**（🔺 见 [17-业务属性四场景与矩阵配置](17-业务属性四场景与矩阵配置.md)）：① 判了**高信任决策 / 搜索承接 / 标准品转化 / 品牌曝光** 哪一型？② 打法与之一致吗（高信任型不追爆款、搜索承接型量大管饱、标准品型先跑 MVP 再复制、品牌曝光型不盯当日成交）？③ **评估指标选对了吗**（品牌曝光型只看咨询数 = 误判，要看品牌词搜索量 + 被看见频次）？④ 老板该不该出镜，按业务类型判了吗（不是凭勇气）？
- [ ] **②⁺⁺ 矩阵三门禁**（🔺🔺 **凡涉及"做矩阵/多号/要几个号"必过**）：① 业务模型跑通了吗（单号已稳定产出咨询）？② 交付链路完整吗（咨询→成交→放大→复购 全通）？③ 团队结构对吗（选题逻辑/内容模板/分发效率/素材速度/复盘机制 五件都有人负责）？**任一项否 = 不许上矩阵，先跑通单号**（矩阵是放大器不是救命药，不满足就上 = 把错误批量复制）
- [ ] **③ 阶段不错位**：接触期+了解期的词 → 节点号 + 低门槛钩子；对比期+决策期的词 → 主 IP 号 + 高客单？
- [ ] **④ 词是真词**：每个关键词都能答"这是我客户在搜，还是我同行在搜"？
- [ ] **④⁺ 能对号入座**（🔺 见 [15-维度乘法与完形填空模板](15-维度乘法与完形填空模板.md)）：① 选题是从**维度相乘**来的，不是拍脑袋想的？② 随机抽 5 条，目标用户看到会不会**自动代入**（"这不就是我吗"）？③ 每条都回答了「**跟我有什么关系**」？（答不上 = 用户在生产自己 YY 的东西，重拆维度）

## 第二关 · 合规关（🔺 最高频翻车点）

- [ ] **⑤ 已扫违禁词**：扫描范围是**标题 3 条 + 正文 + 话题 + 6 张贴图文案 + 5 份评论区脚本**（不含词表本身）？零命中？
- [ ] **⑤⁺ 敏感垂类路线判定**（见 [16-敏感垂类合规边界](16-敏感垂类合规边界.md)）：内容是否属于可验证信息或有边界的主观感受？是否通过换回测试？是否存在预测、诊断、收益或效果承诺？
- [ ] **⑥ 敏感品类已用暗语**：涉国学/命理/八字/男性私密/女性私密/医美等，已按 [09-违禁词与暗语替换表](09-违禁词与暗语替换表.md) 全部替换？
- [ ] **⑦ 降级到位**：敏感品类整篇是「感受 / 生活方式 / 文化知识」表达，**没有功效、诊断、结果承诺**？
- [ ] **⑧ 正文不卖货**：正文无产品名、无价格、无联系方式、无二维码？
- [ ] **⑨ 导流合规**：CTA 只用平台内动作（扣词 / 主页 / 后台滴滴），无站外信息？
- [ ] **⑩ 风险报备**：有无法 100% 规避的点 → 已**显式列出**（哪个词、为什么难替、建议怎么发）？

## 第三关 · 内容关

- [ ] **⑪ 案例有数字且够得着**：有具体数字，既不是"月入十万"也不是"赚杯奶茶钱"？
- [ ] **⑫ 树敌打乱象**：骂的是行业乱象，**没有点名任何具体公司/个人**？
- [ ] **⑬ 答案模糊化**：给了 80% 的价值，留了 20% 的钩子空间？
- [ ] **⑭ 结尾有钩子**：每条都装了留资入口（扣词 / 私信），没忘装？
- [ ] **⑭⁺ 钩子工程四项**（🔺 见 [14-需求拆解与钩子工程](14-需求拆解与钩子工程.md)）：① 钩子档位 L1-L4 选对了？② 钩子价值 **≥ 客单价决策门槛**（卖 1682 的钩子不能只值 9.9）？③ **敢不敢在评论区公开说它值多少钱**（不敢 = 假钩子，一票否决，重做）？④ 「**他的鸡蛋是什么**」那一列填了？
- [ ] **⑮ 人话**：专业术语都翻译过？随便挑一句给非从业者能看懂？

## 第四关 · 贴图与视觉关（🔺 见 [12-贴图尺寸与品类视觉方案](12-贴图尺寸与品类视觉方案.md)）

- [ ] **⑯ 6 张贴图齐全**：封面 / 痛点 / 拆解 / 方法 / 案例 / 钩子，六张分工无缺？
- [ ] **⑰ 尺寸与比例正确**：**1080×1440（3:4）**，六张**同比例**（系统按第一张裁其余），单张 ≤5MB？
- [ ] **⑱ 安全区与字阶正确**：四边留白 ≥88px、**底部 200px 无核心文字**、右侧 120px 无关键信息；主标题 88-104px、最小字号 ≥32px，缩略图能读清？
- [ ] **⑲ 品类视觉方案已应用**：按 [12] 从 13 套常规 / 5 套敏感方案里选了一套？`shot-template.html` 的 `<body>` class 已挂上？背景色+强调色+氛围+产品呈现与本品类的调性一致？
- [ ] **⑳ 敏感品类贴图合规**：涉敏感品类时，贴图上**没有任何禁用元素**（罗盘/符咒/卦象/手掌纹、身体部位、药品胶囊、术前术后对比、真人正脸特写、机构招牌、价格）？
- [ ] **㉑ 封面能打**：第一张图上的大字报，用户刷到 0.5 秒就能看懂并想点？

## 第五关 · 标题、话题与评论区关

- [ ] **㉒ 标题 3 条齐全**：主推 1 + 备选 2，**三种不同打法**（痛点型 / 搜索型 / 反常识型）、每条 ≤20 字、含 1 个搜索词、与封面大字报同一句话？
- [ ] **㉓ 话题合规且配比正确**：8-10 个，泛词 2-3 + 人群词 3-4 + 长尾搜索词 2-3；**敏感品类没用品类词做话题**（命理不打 `#八字`）；全部过 [09] 筛查？
- [ ] **㉔ 5 份评论区脚本齐全**：置顶预埋 / 小号 A 求带 / 小号 B 证言 / 2 小时追问 / 作者回复口径？
- [ ] **㉕ 剧本可执行**：每条都标注了**发布后多久执行 + 用哪台设备的号**？水军号与主号不同设备？

## 第六关 · 交付包与纪律关

- [ ] **㉖ 一键复制齐全**：**27 个入口**（6 图 ×2 + 标题 4 + 正文 2 + 话题 2 + 脚本 6 + 全包 1）逐个测过？本地 `file://` 打开也能复制（有 `execCommand` 兜底）？
- [ ] **㉗ 只出一个交付物**：单文件 HTML + 配套图片，**没有另出纯文字 md**？
- [ ] **㉘ JS 无语法错误**：跑过 `node --check`，通过？
- [ ] **㉙ 算力预算**：开工前声明过预算？50% / 80% 两个自检点走过了？
- [ ] **㉚ 没自行加任务**：只做了用户要的，没"顺便"多做？
- [ ] **㉛ 没自行改标准**：没有我自己加的豁免/兜底/宽松口子？
