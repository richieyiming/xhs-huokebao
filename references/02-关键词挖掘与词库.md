## 1. 逆向工程：三个灵魂拷问

**你被"知识诅咒"了。** 做关键词时本能想到行业词——搜这些词的全是同行，不是客户。

拆需求前先答三问：
1. **谁是你真正的客户？**
2. **他们的真正需求是什么？**
3. **他们在搜索路径的哪个环节，会搜什么词？**

拆得足够细——**内容、体系、账号、下粉逻辑、钩子全部围绕这一个切面打**，就是降维打击。

### 从行业词到品类需求词

| | 案例：香港保险 |
|---|---|
| ✗ 错误 | "香港保险""保诚""品牌名"——搜的全是同行 |
| ✓ 正确 | "香港保险的利率到底是多少？"——真实用户的搜索词 |
| 结果 | 400 个精准粉，出 7 单 |

## 2. 用户决策四阶段 × 搜索词（词库表骨架）

| 阶段 | 用户状态 | 内容策略 | 钩子指向 |
|---|---|---|---|
| **接触期** | 刚听说，想了解行业 | 提问式铺量，擦边泛粉 | 低门槛钩子产品 |
| **了解期** | 已在研究方法 | 模糊答案图文，给方法不给全 | 低门槛钩子产品 |
| **对比期** | 多家对比，犹豫选谁 | 深度种草 · 案例驱动，给案例给结果 | 中高客单产品 |
| **决策期** | 即将买单 | 真实案例复盘 + 学员证言 | 高客单产品 |

**🔺 词库使用铁律**：接触期+了解期的词 → 矩阵号铺量；对比期+决策期的词 → 主 IP 号种草。**两类词不能混着打**，否则内容调性冲突，转化效率低下。

### 素人 IP 行业词库样板（照此结构复制到任何行业）

| 阶段 | 真实搜索词 |
|---|---|
| 接触期 | 普通人怎么做自媒体 / 0 基础怎么做小红书 / 上班族副业做什么好 / 不会拍视频怎么做账号 / 素人能做个人品牌吗 |
| 了解期 | 小红书新手怎么起号 / 素人怎么做个人 IP / 普通人做自媒体能赚钱吗 / 小红书涨粉最快的方法 / 素人 IP 怎么变现 |
| 对比期 | 素人 IP 孵化哪家好 / IP 陪跑靠谱吗 / 个人 IP 陪跑值不值得报 / 素人 IP 孵化避坑 / 花 9800 找人陪跑值不值 |
| 决策期 | 素人 IP 陪跑真实体验 / 个人 IP 陪跑效果怎么样 / 素人 IP 孵化推荐 / 999 IP 咨询有用吗 / IP 陪跑 3 个月值不值 |

**问题型词 > 浏览型词**："个人 IP 怎么定位""我适合做什么 IP"这类问题型搜索，意味着用户已有明确困惑、正在主动找答案，价值远高于浏览型词。

## 3. 母题词库云：往下拆到用户真搜的问题

围绕需求**母题**展开二级、三级词根。

> 例：母题"稳定收益"——用户不搜"稳定收益"四个字，往下拆到"XX 的利率到底是多少""XX 和 YY 比哪个稳"这种真实问题。

**钩子定律**：在用户找你的那一个搜索路径上下钩子，才是最快最大效果的钩子。每个路径下的母题再盘二级、三级词根，全部笼络。

---

## 4. 挖词操作（每周一循环）

1. 小红书搜索框输入**种子词**，记录下拉推荐词
2. 记录搜索结果里的**笔记标题**（这些是被验证过的真实搜索承接内容）
3. 用千瓜 / 灰豚等工具拉搜索热度词
4. 按四阶段分类整理，**每阶段至少 20-30 个真实搜索词**
5. 用前先自检：这个词是我同行在搜，还是我客户在搜？

## 5. 完形填空法：一套框架批量产 100 条

**框架不变，只替换变量。** 框架是骨架，变量是血肉。

| 人群变量 | 提问式（接触期） | 模糊答案（了解期） |
|---|---|---|
| 上班族 | 上班族到底能不能做小红书 IP？有没有上班的姐妹做起来的？ | 上班族做 IP 最大的坑是什么？不是时间不够，是定位错了…… |
| 宝妈 | 宝妈在家做 IP 到底靠不靠谱？有没有带娃做起来的？ | 宝妈做自媒体，时间碎片化怎么破？关键在选题方向…… |
| 大学生 | 大学生做自媒体 IP 有没有前途？ | 大学生做 IP 最大的优势是什么？不是时间，是试错成本…… |
| 实体店老板 | 实体店老板转线上做 IP 到底行不行？ | 实体店老板做 IP，最容易踩的坑就是把自己当网红做…… |
| 设计师 | 设计师做个人 IP 能变现吗？ | 设计师做 IP 的核心不是作品集，是客户痛点定位…… |
| 企业中层 | 30+ 职场人做 IP 还来得及吗？ | 中层管理做 IP，最大的卡点不是能力，是思维转变…… |
| 教师 | 老师下班后做副业 IP 会怎样？ | 老师做 IP 最大的误解是什么？以为要露脸拍视频…… |
| 护士 | 护士做自媒体到底可不可行？ | 护士倒班怎么做 IP？关键在选题方向不是时间…… |

**生产公式**：8 个人群变量 × 2 种框架 = 16 条种子 → 每条换 3-5 个角度（1 个月/3 个月/半年）= 48-80 条 → × 5 个矩阵号 = 240-400 条内容池，够跑 3 个月。

## 6. 黄金流量提问句库

**火的不是框架，是那句话。** 找到行业的"黄金提问句"，批量复制必然都有流量。

筛选标准（四条全中才算）：
1. 能引发讨论（评论区自然想说话）
2. 戳中真实焦虑（身份焦虑/收入焦虑，不是知识焦虑）
3. 答案可以模糊化（给一部分，留钩子空间）
4. 可以套不同人群变量（完形填空）

样板句：
> 普通人到底能不能做 IP？ / 0 基础素人做小红书该从哪开始？ / 花 9800 找人陪跑做 IP，到底值不值？ / 上班族想辞职做自媒体靠谱吗？ / 素人做了 3 个月 IP，到底做对了什么？ / 不会拍视频的人能做 IP 吗？ / 做 IP 第一步到底该干什么？ / 小红书 0 粉素人怎么起号？ / 宝妈在家做 IP 有人成功吗？ / 做个人 IP 是不是割韭菜？

**写文案必须用真实用户视角。** 年入千万的老板不会问"怎么赚钱"，他会问"年入千万，离婚了，心情郁闷，公司也遇到瓶颈怎么办？"——利用人性中"好为人师"的特质。

## 7. 操盘手心法

**"既贩毒又吸毒"**——操盘手自己就是消费者，刻意去搜索、体验用户的决策动线，据此设计内容。不复盘自己的搜索体验，就想不出用户在搜什么。
